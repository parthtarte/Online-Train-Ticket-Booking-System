# Online Train Ticket Booking System

## Technologies Used
- Python
- HTML
- CSS
- JavaScript
- MySQL

## Features
- User Registration and Login
- Train Search Functionality
- Ticket Booking System
- Passenger Record Management
- Database Connectivity using MySQL

## Project Description
This project is an online train ticket booking system developed using Python, HTML, CSS, JavaScript, and MySQL. It allows users to search trains, book tickets, and manage passenger records through a user-friendly interface.
